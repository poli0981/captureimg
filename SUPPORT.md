# Getting help

CaptureImage is maintained by one volunteer. Here is where to go:

| You want to… | Go to |
|---|---|
| Ask a question or share an idea | [GitHub Discussions](https://github.com/poli0981/captureimg/discussions) |
| Report a bug | [Bug report](https://github.com/poli0981/captureimg/issues/new?template=bug_report.yml) — or **About → Report a bug** in the app |
| Suggest a feature | [Feature request](https://github.com/poli0981/captureimg/issues/new?template=feature_request.yml) |
| Report a security problem | Privately — see [`SECURITY.md`](SECURITY.md) (`security@poli0981.dev`) |
| Ask about privacy | `privacy@poli0981.dev` — see [`docs/legal/PRIVACY.md`](docs/legal/PRIVACY.md) |
| Raise a game-compatibility or anti-cheat concern (publishers, vendors) | `games@poli0981.dev` |
| Copyright, DMCA or takedown requests | `dmca@poli0981.dev` · `takedown@poli0981.dev` |
| Sponsor the project | `sponsor@poli0981.dev` or the links in the [README](README.md#support-the-project) |
| Anything else | `contact@poli0981.dev` · <https://poli0981.dev/links> |

## Before reporting a bug

1. Update to the [latest release](https://github.com/poli0981/captureimg/releases/latest) — it may
   already be fixed.
2. In the app, open **Settings → Advanced**, set the log level to **Debug**, reproduce the problem,
   then use **Export diagnostics**. The zip contains logs, settings and system information with your
   user paths removed; attach it to the issue if you're comfortable with that.
3. For capture problems, say which game, whether it runs windowed, borderless or full screen, and
   whether you use HDR or several monitors.

There is no paid support or guaranteed response time, but every report is read.
